# 火把袋 Torch Bag

[繁體中文](README.md) · [简体中文](README.zh_CN.md) · [English](README.en.md)

适用于 Minecraft Forge 1.20.1 和 NeoForge 1.21.1 的自动放火把模组。当前版本：0.6.0。

## 安装

1. 下载与游戏版本相同的 JAR，放进游戏实例的 `mods` 文件夹。
2. 多人游戏时，服务器与所有玩家都需要安装本模组。
3. Curios API 为可选依赖。安装后玩家会自动获得一个“腰带”栏位。
4. Sophisticated Backpacks 和 Sophisticated Core 也是可选依赖；安装后火把袋可以从背包中取得火把。

Forge 1.20.1 与 NeoForge 1.21.1 的 JAR 不能混用。

## 火把袋

- 右键打开收纳界面，只能放入原版普通火把。
- 容量为 54 格，相当于一个大型箱子。
- 手持主手、副手，或装备在 Curios 的腰带栏位时，会自动为黑暗区域补充火把。
- 穿戴时按 `V` 可打开火把袋；按键可在游戏设置中修改。
- 右侧齿轮可设置自动补光半径：8、16、32、64 格，默认 16 格。
- 火把优先从火把袋取用，然后是玩家背包，最后是 Sophisticated Backpacks。

火把袋配方：

| 皮革 | 火把 | 皮革 |
|---|---|---|
| 火把 | 箱子 | 火把 |
| 皮革 | 末影珍珠 | 皮革 |

## 火把爆弹

火把爆弹 I、II、III 的范围分别为 4、8、16 个区块：

| 等级 | 区块范围 | 区块数量 |
|---|---:|---:|
| I | 9×9 | 81 |
| II | 17×17 | 289 |
| III | 33×33 | 1,089 |

I 由四个煤炭块围住一个末影之眼合成；两个 I 可合成 II，两个 II 可合成 III。

右键会消耗一颗爆弹，并从使用位置所在区块开始按螺旋顺序向外补光。创造模式不消耗。爆弹只尝试照亮与释放位置相通的空间，因此不会直接穿过完整墙壁或进入密闭房间。

为了更快完成，普通区块只会检查 25 根代表柱，中心区块最多检查 36 根；判断到可放置的位置会立即插火把。这个取舍意味着极窄、弯曲很多次的通道可能被略过。Boss Bar 显示“火把放置进度”；进度到 100% 前，同一玩家不能使用第二颗。多个玩家的重叠范围会共享近期放置记录，避免出现双倍密度。

## 开发与验证

- `forge-1.20.1/` 使用 Java 17 和 Forge 47.4.10。
- `neoforge-1.21.1/` 使用 Java 21 和 NeoForge 21.1.251。
- `scripts/generate_sources.py` 和 `scripts/generate_resources.py` 用于生成两套版本的共同内容。
- 每个版本都在完整依赖、无可选依赖、只装 Curios、只装 Sophisticated Backpacks 四种组合下运行了 10 项 GameTest。

详细验证记录见 [TESTING.md](TESTING.md)。
